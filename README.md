## 📚 About the Project 
More than just basic endpoints, this API is a <b>learning lab</b> covering fundamentals through advanced Spring practices:

<p align="left">
  <img src="https://i.gifer.com/3Wby.gif" width="180">
</p>

- ✅ REST endpoint creation  
- ✅ Persistence with Spring Data JPA (relationships, transactions, entity states)  
- ✅ Advanced queries: JPQL, Query Methods, Specifications  
- ✅ Entity mapping with <b>MapStruct</b>  
- ✅ Validations and error handling  
- ✅ Security with <b>Spring Security</b>, Roles, JWT and OAuth2  
- ✅ Documentation with <b>Swagger</b>  
- ✅ Deployment with <b>Docker</b> and <b>AWS integration</b>  
- ✅ Logging, metrics, and monitoring with <b>Actuator</b>
